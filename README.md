# قنطار — الواجهة

تطبيق React عبر Vite مع PWA، يستهلك `qintar-backend` عبر `/api/v1/`.

**المرجع التقني كله في مستودع `qintar-backend`.** هنا الواجهة وحدها: لا قاعدة بيانات، ولا منطق مالي، ولا سر.

اقرأ `CLAUDE.md` قبل أي عمل.

## التشغيل

```bash
npm install
npm run dev        # يولّد التوكنات ثم يشغّل Vite على 5173
```

الطلبات تُمرَّر إلى `http://localhost:8000`، فشغّل `php artisan serve` في `../api` أولًا.

## الأوامر

| الأمر | ما يفعله |
|---|---|
| `npm run dev` | تطوير |
| `npm run build` | توكنات ثم فحص أنواع ثم بناء |
| `npm test` | اختبارات المال وحُرّاس قواعد الواجهة |
| `npm run tokens` | يولّد `src/styles/tokens.css` من `shared/design-tokens.json` |
| `npm run shared:check` | يتحقق أن `shared/` يطابق بصمته |

## الحُرّاس

| الحارس | ماذا يمنع |
|---|---|
| `frontend-guards` | Hex مباشر · `parseFloat` على مبلغ · `100vh` · استيراد حزمة مراقبة الأخطاء · تباعد نصوص الموافقة عن الخلفية |
| `money.test` | تراكم خطأ الفاصلة العائمة في المبالغ |
| `shared:check` | انحراف `shared/` عن بصمته |

كلها مختبَرة بالفشل لا بالنجاح وحده: خرقٌ متعمَّد يجب أن يوقف البناء.

## البنية

| المسار | ما هو |
|---|---|
| `shared/` | التوكنات والفئات ونصوص الموافقة — **منسوخة من الخلفية، لا تُعدَّل هنا** |
| `src/lib/money.ts` | المال نصوص عشرية. لا حساب خارج هذي الدوال |
| `src/api/` | طبقة الاستهلاك وأنواع الاستجابة و hooks |
| `src/lib/offline/` | طابور المسودات: تظهر «مسودة» ولا تدخل في أي رقم حتى تُزامَن |
| `src/screens/` | اثنتا عشرة شاشة |
